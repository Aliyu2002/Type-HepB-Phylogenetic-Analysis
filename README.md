# In-Silico Phylogenetic Analysis of Hepatitis B Virus (HBV) in Nigeria

## 📌 Project Overview
This repository contains an end-to-end computational biology pipeline engineered to track the genetic variance and evolutionary relationships of Hepatitis B (HBV) isolates in West Africa. 

Operating at the intersection of clinical diagnostics and genomic epidemiology, this project bridges the gap between grassroots wet-lab seroprevalence screening (identifying *who* is infected) and computational pathogen tracking (understanding *how* the virus is mutating and spreading).

## 🔬 Clinical & Translational Significance
In rural and resource-limited settings like Northern Nigeria, routine clinical screening for HBV relies on detecting the Hepatitis B surface antigen (HBsAg). While critical for immediate patient care, physical diagnostics cannot track viral transmission networks or detect **vaccine escape mutants** (polymorphisms in the surface gene that allow the virus to evade standard vaccine-induced antibodies).

This pipeline was built to scale local diagnostic efforts into global surveillance. By aligning local genomic sequences, we can identify Single Nucleotide Polymorphisms (SNPs) and pyrimidine transitions that inform vaccine efficacy, viral divergence, and public health interventions.

## ⚙️ Computational Pipeline
The pipeline is executed entirely in Python (Jupyter environment) and handles the data in three automated phases:

1. **Programmatic Data Mining:** 
   - Utilizes the `Biopython Entrez API` to directly query the NCBI Nucleotide database.
   - Filters and downloads complete HBV viral genomes isolated in Nigeria in standard `.fasta` format.
2. **Multiple Sequence Alignment (MSA):**
   - Bypasses basic pairwise wrappers to command the local **MUSCLE** (Multiple Sequence Comparison by Log-Expectation) engine.
   - Generates a mathematically optimized alignment matrix to highlight nucleotide substitutions and deletions across all strains simultaneously.
3. **Phylogenetic Reconstruction:**
   - Calculates genetic distance matrices utilizing the `DistanceCalculator('identity')` algorithm.
   - Deploys the **Neighbor-Joining (NJ)** algorithm via `DistanceTreeConstructor` to reconstruct the evolutionary tree.
   - Renders the final visual cladogram using `matplotlib`.

## 📁 Repository Structure
* `HepatitisB_Analysis.ipynb`: The core Jupyter notebook containing all Python execution scripts, API calls, and visual outputs.
* `HepB_Nigeria_Genomes.fasta`: The raw genomic data mined from NCBI.
* `HepB_Aligned.fasta`: The final alignment matrix generated by the MUSCLE engine.

## 🛠️ Tools & Dependencies
* **Language:** Python 3.x
* **Libraries:** Biopython, Matplotlib, OS, Subprocess
* **Alignment Engine:** MUSCLE (v5.1)
